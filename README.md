🌤 점심시간에 나가도 돼요? (점심시간 장소 추천 앱)기상청 단기예보 API를 활용하여, 기온과 강수확률을 바탕으로 안전한 점심시간 놀이 장소(운동장, 필로티, 교실)를 추천해 주는 Streamlit 웹 어플리케이션입니다.1. 설치 (Installation)이 앱을 실행하기 위해서는 파이썬 패키지들이 필요합니다. 터미널(또는 명령 프롬프트)에서 다음 명령어를 입력하여 설치해 주세요.pip install streamlit pandas requests
2. 실행 (Execution)패키지 설치가 완료되면, 터미널에 아래 명령어를 입력하여 웹 어플리케이션을 실행합니다.streamlit run app.py
3. 샘플 데이터 형식 (Sample Data Format)본 어플리케이션은 기상청 API를 실시간으로 호출하므로 별도의 로컬 데이터 파일(CSV 등)을 필수로 요구하지 않습니다. 하지만 내부적으로 가공되어 화면에 출력되는 데이터(sample.csv로 저장 시)의 구조는 다음과 같습니다.구분날짜기온(°C)강수확률(%)추천 장소오늘05/29 (금)22.50운동장내일05/30 (토)28.040필로티모레05/31 (일)10.510교실4. 한계 항목 (Limitations)지역적 한계: 현재 경기도 내 31개 시·군 지역의 기상청 격자 좌표만 등록되어 있어 타 지역은 조회가 불가능합니다.시간적 한계: 단기예보 특성상 '오늘~모레'의 예보만 제공되며, 점심시간(12시~13시) 기준의 날씨만 추출하여 판별합니다.API 의존성 한계: 공공데이터포털 기상청 서버의 혼잡도나 점검 상태에 따라 예보 데이터를 불러오는 데 지연이 발생하거나 일시적인 오류가 날 수 있습니다.
