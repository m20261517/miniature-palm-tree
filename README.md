# {{점심시간에 나가도 돼요?}}

경기도 지역의 날씨와 미세먼지에 따라 안전한 점심시간 놀이 장소를 추천하고, 장소에 맞는 놀이와 안전수칙을 안내하는 앱입니다.

> 2026-1학기 클라우드 프로그래밍 · M20261517/주민경

---

## 1. 무엇을 할 수 있나요

1. **지역 선택 및 날씨 데이터 준비**: 지역선택 탭에서 원하는 도시를 클릭하면 기상청 단기예보 조회서비스 오픈API를 통해 날씨 데이터를 불러옵니다.
2. **날짜별 장소 추천 확인**: 3일 동안의 날씨와 미세먼지 정보가 표로 표시되며, 해당 날짜의 기상 상황(기온, 강수확률)과 현재 미세먼지(PM10) 수준에 따라 운동장, 필로티, 교실 중 알맞은 활동 공간을 추천합니다.
3. **추천 놀이 및 맞춤형 안전 수칙 안내**: 추천된 장소에 맞는 놀이 활동의 방법을 팝오버 형태로 확인하고, 기온, 강수확률, 미세먼지 수준을 고려한 안전 수칙을 확인할 수 있습니다.

## 4. 데이터 소스 (실시간 API)

본 프로젝트는 개인정보가 담긴 외부 CSV 파일 업로드 없이, 공공데이터포털 API를 통한 실시간 데이터만을 사용합니다.

### 4-1. 기상청 단기예보 API
오늘~모레 3일간의 기온(TMP)과 강수확률(POP) 데이터를 제공합니다.

| 항목 | 타입 | 범위/기준 | 필수 |
|------|------|---------|------|
| **TMP (1시간 기온)** | JSON | 12°C~30°C 범위 내일 때 야외 활동 가능<br>(범위 이탈 시 교실 추천) | ✅ |
| **POP (강수확률)** | JSON | 30% 미만일 때 운동장 추천<br>(30% 이상 시 필로티 추천) | ✅ |

### 4-2. 에어코리아 API (신규)
현재 시각 기준 경기도 각 시·군의 미세먼지(PM10) 농도와 등급 정보를 제공합니다.

| 항목 | 타입 | 기준 | 필수 |
|------|------|-----|------|
| **PM10 (미세먼지 농도)** | JSON | ㎍/㎥ 단위<br>0~30 좋음 / 31~80 보통 / 81~150 나쁨 / 151~ 매우나쁨 | ✅ |
| **PM10 등급** | JSON | 1(좋음) ~ 4(매우나쁨) | ✅ |
| **데이터 기준시각** | JSON | 마지막 갱신 시각 | ℹ️ |

## 5. 장소 추천 로직

### 종합 판정 알고리즘
미세먼지 수준이 최우선 안전 기준으로 적용됩니다:

1. **미세먼지 '나쁨'(grade 3) 이상** → 기온/강수와 무관하게 **교실** 추천
2. **기온 범위 이탈** (< 12°C 또는 > 30°C) → **교실** 추천
3. **강수확률 높음** (≥ 30%) → **필로티** 추천
4. **기온 적절 + 강수확률 낮음** (12~30°C, < 30%) → **운동장** 추천

### 추천 표시
각 추천마다 판정 근거가 명시되며, 기온·강수확률·미세먼지 정보가 함께 표시됩니다.

## 6. 프로젝트 한계 및 향후 과제 (Limitations)

- **데이터 영구 저장 불가**: 현재 세션 기반으로 작동하여 화면 새로고침 시 데이터가 초기화됩니다. (추후 학기 단위 비교를 위한 DB 연동 필요)
- **단기예보 기간 제약**: 기상청 단기예보 API는 3일 범위만 지원합니다. (중기예보 확장은 별도 API 필요)
- **미세먼지 데이터 한계**: 에어코리아 API는 "현재" 데이터만 제공하므로, 각 날짜의 예상 미세먼지 수준을 예측하지 못합니다. (향후 시계열 데이터 수집 필요)
- **측정소 매핑 오류**: 일부 시군에서 에어코리아 측정소명이 정확하게 매핑되지 않을 수 있어, 가장 최근 데이터를 대표값으로 표시합니다.
- **Out of Scope (범위 외)**: 로그인 / 외부 AI API / 이메일 발송 / 모바일 반응형 UI
