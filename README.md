# {{점심시간에 나가도 돼요?}}

경기도 지역의 날씨에 따라 안전한 점심시간 놀이 장소를 추천하고, 장소에 맞는 놀이와 안전수칙을 안내하는 앱입니다.

> 2026-1학기 클라우드 프로그래밍 · M20261517/주민경

---

## 1. 무엇을 할 수 있나요

1. **지역 선택 및 날씨 데이터 준비**: 지역선택 탭에서 원하는 도시를 클릭하면 단기예보 조회서비스 오픈API를 통해 날씨 데이터를 불러옵니다.
2. **날짜별 장소 추천 확인**: 3일 동안의 날씨가 표로 표시되며, 해당 날짜의 기상 상황(기온, 강수확률)에 따라 운동장, 필로티, 교실 중 알맞은 활동 장소와 판정 근거를 추천합니다. 
3. **추천 놀이 및 맞춤형 안전 수칙 안내**: 추천된 장소에 맞는 놀이 활동의 방법을 팝오버 형태로 확인하고, 현재 기온 및 강수 확률에 맞춘 안전 수칙을 확인할 수 있습니다. 

## 2. 설치 및 로컬 실행

자신의 컴퓨터에서 직접 실행해 보려면 아래의 명령어를 순서대로 입력하세요.

```bash
# 1. 가상환경 생성 및 활성화
python -m venv .venv
source .venv/bin/activate  # Windows의 경우: .venv\Scripts\activate

# 2. 필수 라이브러리 설치
pip install -r requirements.txt

# 3. 앱 실행
streamlit run app.py
```

3. **Deploy** 버튼 클릭

## 4. 샘플 데이터 형식 (CSV 대신 실시간 API 사용)

본 프로젝트는 개인정보가 담긴 외부 CSV 파일 업로드 없이, 기상청 단기예보 API의 기온과 강수확률 데이터(JSON)만을 실시간 입력값으로 사용합니다.

| 컬럼명 (API 항목) | 타입 | 기준 예시 | 필수 |
|--------|------|------|------|
| `TMP (1시간 기온)` | JSON | 12°C~30°C 범위 내일 때 야외 활동 가능 (범위 이탈 시 교실 추천) | ✅ |
| `POP (강수확률)` | JSON | 30% 미만일 때 운동장 추천 (30% 이상 시 필로티 추천) | ✅ |

* **종합 장소 판정 조건**: 기온이 적절하고(12°C~30°C) 강수확률이 낮으면(30% 미만) **'운동장'** 활동을 최우선으로 추천합니다.
* **보안 체크**: 학생 이름 등 개인정보가 포함된 데이터는 취급하지 않으며, `.gitignore`를 통해 시스템 파일 업로드를 차단합니다.

## 5. 프로젝트 한계 및 향후 과제 (Limitations)

- **데이터 영구 저장 불가**: 현재 세션 기반으로 작동하여 화면 새로고침 시 데이터가 초기화됩니다. (추후 학기 단위 비교를 위한 DB 연동 필요)
- **API 연동 한계**: 관측소 매핑 오류로 인한 '미세먼지 조회 API' 구동 실패 및 '기상청 중기 예보 API' 미지원으로, 현재는 3일간의 단기 예보 판별만 제공합니다.
- **Out of Scope (범위 외)**: 로그인 / 외부 AI API / 이메일 발송 / 모바일 반응형 UI
